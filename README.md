# インターバル・タイマー 導入手順

このフォルダの中身をインターネット上に置く（公開する）と、どのiPadでもSafariで開いて、ホーム画面にアプリとして追加できます。
一度開けば、その後は庭などネットがつながらない場所でも動きます。

## 入っているファイル
| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.json | ホーム画面に追加したときの名前やアイコンの設定 |
| sw.js | オフラインでも動くようにする仕組み |
| icon-180.png / icon-192.png / icon-512.png | ホーム画面のアイコン |

## 手順1：公開する（最初の1回だけ）
無料の「GitHub Pages」を使う方法です。パソコンでもiPadのブラウザでも操作できます。

1. GitHub（github.com）で無料アカウントを作ります。
2. 右上の「＋」→「New repository」で新しいリポジトリを作ります。名前は例として `interval-timer`、公開範囲は「Public」を選びます。
3. 作ったリポジトリで「Add file」→「Upload files」を選び、このフォルダの中のファイル（6つ）をすべてアップロードして「Commit changes」を押します。
4. リポジトリの「Settings」→「Pages」を開き、「Branch」で `main` と `/ (root)` を選んで「Save」を押します。
5. 数分待つと、`https://ユーザー名.github.io/interval-timer/` のアドレスでアプリが開けるようになります。

※ アドレスを知っている人なら誰でもアプリを開けますが、記録は各iPadの中にだけ保存されるため、他の人に見られることはありません。

## 手順2：各iPadに追加する
1. iPadのSafariで、手順1のアドレスを開きます。
2. 共有ボタン（□に↑のマーク）→「ホーム画面に追加」を押します。
3. ホーム画面の「インターバル」アイコンから起動します。

## 記録を別のiPadに移すとき
記録は各iPadの中に保存されるため、iPad同士で自動では共有されません。
1. 元のiPadで「設定」→「記録を書き出す」を押し、ファイルを保存します。
2. そのファイルをAirDropやメールで、移したいiPadに送ります。
3. 移したいiPadで「設定」→「記録を読み込む」を押し、ファイルを選びます。

読み込んだ記録は今ある記録に追加され、同じ記録が重複することはありません。

## 使う前の確認
- 音が出ないときは、iPadの音量と消音モードを確認してください。
- 途中で画面が消えるときは、「設定」→「画面表示と明るさ」→「自動ロック」を「なし」にしてください。
- アプリを更新したときは、新しい index.html を同じ場所にアップロードし直すだけで、各iPadに反映されます（反映にはネットにつながった状態で1〜2回アプリを開く必要があります）。
